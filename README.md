# 小栞题库

手机优先的中文静态刷题网页，无运行依赖、外网 CDN、字体或接口请求。支持系统深色与浅色模式。

## 打开网页

直接用浏览器打开 `index.html`。`questions.js` 已生成，不需要启动服务器或安装依赖。手机可将文件放到静态网站服务器访问。部署时保留同一目录下的 `index.html`、`style.css`、`app.js` 和 `questions.js`。

首次构建或更新题库需要 Node.js，无须安装 npm 包：

```sh
node build.js
node validate.js
```

校验会在独立执行环境加载 `questions.js`，确认总数为 110（组织学 30、物理 49、测量 31）、ID 唯一，原文、答案、来源、章节页码和核实标记完整。更新题目数量时请同步调整 `validate.js` 中的预期总数和各科数量。

## 更新题库

1. 编辑 `zuzhi.json`（组织学）、`wuli.json`（物理）、`celiang.json`（测量）。每份文件顶层是 JSON 数组，使用 UTF-8。
2. 每题保留 `subject`、`type`、`question`、`options`、`answer`、`explanation` 六个字段。题型使用“单选”“判断”“填空”“简答”“计算”“论述”。物理题还保留 `chapter`（7–10）和 `page`。主观题 `options` 使用空数组；单选、判断的 `answer` 可使用选项字母（如 `C`）、带选项文本（如 `C. xxx`）、带说明的字母或明确写出选项的长文本。判断题也使用选项，例如 `A. 对`、`B. 错`。
3. 运行 `node build.js` 合并生成 `questions.js`，再运行 `node validate.js`。不要直接编辑生成文件，下次构建会覆盖。
4. 重新打开或刷新网页；静态服务器需要同步更新 `questions.js`，并留意浏览器缓存。

题目示例：

```json
{
  "subject": "物理",
  "type": "单选",
  "question": "两个正点电荷之间的静电力属于哪种作用？",
  "options": ["A. 引力", "B. 斥力"],
  "answer": "B",
  "explanation": "同种电荷相互排斥。"
}
```

构建脚本自动补全：

- `id`：由文件名、科目、题型和题干生成稳定 ID。调整题目顺序、修改答案或解析不会改变 ID。修改题干会生成新 ID；需要延续记录时，可在原始 JSON 中填写旧 `id`。重复 ID 或重复题目会导致构建报错。
- `answerMode`：可从答案中明确识别有效选项时为 `choice`，并将 `answer` 规范化为选项字母；否则为 `self`，保留答案文本并通过“显示答案”自评，不丢题、不修改原题型。填空题一律自评。`originalAnswer` 始终保留原答案文本。
- `source`：物理统一为“老师指定练习题原题”；其余默认“小栞整理”，可在原始 JSON 中指定来源。
- `verified`：原始题目任意字段包含“待核实”时为 `false`，否则为 `true`。这是文本标记，不代表已经完成学术校对。核实后请修订题目并移除这段标记，再重新构建。

## 练习与错题

- 选择科目、题型和顺序；物理日常练习及错题本还可按第7–10章筛选，题目卡片显示章节和页码。随机模式先打乱符合条件的完整题集，同一轮不会重复抽题。
- 能识别答案的单选、判断点选后立即判题并显示解析。其余题目先在输入框独立作答，再点“显示答案”，对照参考答案自评。
- 答错自动进入错题本，之后答对自动移出。进入错题本时按最新错题组卷；本轮中已改正的题仍可回看。
- 答题位置、随机顺序、草稿、判题结果、错题和模拟卷通过 `localStorage` 保存在当前浏览器。刷新后继续，切换筛选条件后也可回到之前的练习。
- “完成本轮”会询问是否重新开始本轮练习，累计进度和错题会保留。“再练一次”只重置当前题本轮的作答。
- 记录不跨设备、不上传。清除浏览器网站数据会删除记录；隐私模式、禁用存储或空间不足时页面会提示。直接打开文件时，存储行为由浏览器决定；长期使用建议固定在同一个静态站点地址。

## 模拟考试

按科目随机抽取，同一张卷不重复抽题，题型分组排列：

| 科目 | 单选 | 判断 | 简答 | 计算 | 论述 | 大题（计算/填空） | 目标合计 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 组织学 | 10 | 10 | 6 | 1 | 1 | 0 | 28 |
| 物理 | 10 | 10 | 0 | 0 | 0 | 8 | 28 |
| 测量 | 0 | 0 | 0 | 4 | 0 | 0 | 4 |

需求未明确组织学计算、论述数量，目前暂各取 1 题，页面也会说明。可修改 `app.js` 顶部的 `EXAM_STRUCTURE`。物理从全章节抽题，大题从计算、填空的合并题池抽取，每类不足目标数量时全部选入。当前物理原题没有判断题，因此实际模拟卷为单选 10 + 大题 8 = 18 题，页面按实际数量展示。其他科目题型不足时仍提示并阻止开考。

交卷前可切换题号、修改作答，不展示参考答案；交卷后自动批改客观题，主观题显示参考答案供自评。空白题按错误计入，主观题全部自评后显示完整结果。每题按答对题数统计，未设置考试时长与分值权重。错题同步进入错题本，待核实标签仍保留。每个科目的模拟卷分别保存，完成后可回顾或重新抽卷。

## 文件

- `index.html`、`style.css`、`app.js`：页面、响应式样式、交互。
- 三份原始 JSON：题库编辑入口。
- `build.js`：校验基础格式，生成合并题库。
- `questions.js`：浏览器直接加载的题库。
- `validate.js`：用 Node 校验生成题库。
